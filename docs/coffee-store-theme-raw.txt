P14|IMG=N|Theme Component Documentation & Developer Requirements
P16|IMG=N|Overview
P17|IMG=N|The Promotional Announcements component is a customizable element within the e-commerce theme editor. It allows store owners to create, manage, and display promotional announcement bars on their storefront. The component must be responsive, fully customizable, and compatible with desktop and mobile devices.
P18|IMG=N|1. Component Header and General Information
P19|IMG=N|Promotional Announcements
P20|IMG=N|The component name displayed in the theme editor. It provides access to the settings used to manage promotional announcement bars.
P21|IMG=N|Customizable
P22|IMG=N|Indicates that the component supports customization through the theme editor, including announcement text, colors, activation status, display order, and display mode.
P23|IMG=N|Announcement Count and Independent Management
P24|IMG=N|The interface displays the number of announcements currently configured (for example, “2 announcements | Manage each announcement independently”). Each announcement must have its own settings so editing one does not unintentionally affect another.
P25|IMG=N|2. Individual Announcement Card
P26|IMG=N|2.1 Active — Enable or Disable an Announcement
P27|IMG=N|Controls whether an individual announcement is eligible to appear on the storefront.
P28|IMG=N|When enabled, the announcement becomes eligible for display.
P29|IMG=N|When disabled, it remains saved in theme settings but is excluded from the storefront.
P30|IMG=N|If all announcements are disabled, hide the announcement bar.
P31|IMG=N|2.2 Announcement 1 / Announcement 2 — Announcement Identifier
P32|IMG=N|Displays the announcement position or identifier in the management interface. Each announcement must have a stable, unique internal ID so editing, deleting, activating, or reordering one does not affect another.
P33|IMG=N|2.3 Announcement Preview Bar
P34|IMG=N|Displays the announcement text using the currently selected text and background colors.
P35|IMG=N|Updates immediately when the text or colors change.
P36|IMG=N|Reflects the current configuration before changes are saved.
P37|IMG=N|2.4 Announcement Text
P38|IMG=N|A text field used to define the promotional message displayed to storefront visitors.
P39|IMG=N|Example: “Free shipping on orders over SAR 200.”
P40|IMG=N|Allow the store owner to enter or edit the text.
P41|IMG=N|Support Arabic and English, including long messages.
P42|IMG=N|Allow text to wrap onto multiple lines when necessary.
P43|IMG=N|Prevent empty announcements from appearing on the storefront.
P44|IMG=N|Important: Announcement text is informational only. A message about free shipping or a discount does not implement the promotion unless a separate promotion or discount mechanism is connected.
P45|IMG=N|2.5 Text Color
P46|IMG=N|Defines the announcement text color. Example: #FFFFFF for white.
P47|IMG=N|Accept valid HEX color codes.
P48|IMG=N|Apply the selected color to the corresponding announcement only.
P49|IMG=N|Update the preview immediately and preserve the color after saving.
P50|IMG=N|2.6 Background Color
P51|IMG=N|Defines the announcement bar background color. Examples: #173B35 (dark green) and #8B1E3F (burgundy).
P52|IMG=N|Allow independent background colors for each announcement.
P53|IMG=N|Validate the color value before applying it.
P54|IMG=N|Update the preview immediately and preserve the color after saving.
P55|IMG=N|Maintain sufficient contrast between text and background.
P56|IMG=N|2.7 Delete
P57|IMG=N|Ask for confirmation before permanent deletion.
P58|IMG=N|Delete only the selected announcement.
P59|IMG=N|Preserve all other announcements and their settings.
P60|IMG=N|Update the announcement count, list, order, and preview.
P61|IMG=N|If the deleted announcement is currently displayed, move to the next eligible announcement when applicable.
P62|IMG=N|Hide the bar if no eligible announcements remain.
P63|IMG=N|2.8 Move Up / Move Down
P64|IMG=N|Move Up moves the announcement one position higher.
P65|IMG=N|Move Down moves the announcement one position lower.
P66|IMG=N|Disable Move Up for the first announcement and Move Down for the last.
P67|IMG=N|Preserve the new order after saving and apply it to relevant storefront display modes.
P68|IMG=N|Reordering must not change the announcement text, colors, activation status, or unique ID.

P81|IMG=N|Prepare the updated configuration for saving.

P98|IMG=N|Maintain consistent spacing between bars.
P99|IMG=N|Adapt the layout to desktop and mobile screen widths.
P100|IMG=N|Exclude disabled or invalid announcements.
P101|IMG=N|4.3 Display Only One Announcement by Order
P102|IMG=N|Displays one announcement at a time according to the configured order. The intended navigation behavior must be explicitly defined during implementation.
P103|IMG=N|Display the first eligible announcement by default.
P104|IMG=N|Provide previous and next controls if manual navigation is intended.
P105|IMG=N|Navigate only between eligible announcements.
P106|IMG=N|Follow the saved order.
P107|IMG=N|Update the displayed announcement when the current announcement is disabled or deleted.
P108|IMG=N|Hide the bar when no eligible announcements remain.

P110|IMG=N|Disabled announcements must never appear on the storefront.
P111|IMG=N|Changes to announcement order must be reflected in relevant display modes.
P112|IMG=N|Deleted announcements must be removed from the displayed sequence.
P113|IMG=N|Invalid or empty announcements must be excluded.
P114|IMG=N|The selected display mode must persist after saving and reloading the theme editor.

P132|IMG=N|6. What Happens After Editing and Saving?
P133|IMG=N|The implementation must distinguish between editing settings, saving the configuration, and publishing changes to the live storefront.
P134|IMG=N|Step 1: Edit the Settings
P135|IMG=N|The store owner changes announcement text, colors, activation status, order, or display mode.
P136|IMG=N|Step 2: Update the Preview
P137|IMG=N|The editor reflects current changes immediately so the store owner can inspect the result before saving.
P138|IMG=N|Step 3: Validate the Configuration
P139|IMG=N|Validate announcement text, HEX color values, unique IDs, announcement order, display mode selection, and any required fields. Handle invalid values without corrupting existing settings.
P140|IMG=N|Step 4: Save the Configuration
P141|IMG=N|Save the announcement list and its settings: unique IDs, text, text colors, background colors, activation status, display order, selected display mode, and any supported rotation settings.
P142|IMG=N|Step 5: Apply or Publish the Changes
P143|IMG=N|After successful saving and any required publishing step, the storefront must use the updated configuration. If saving and publishing are separate, changes are not live until publishing is complete.
P144|IMG=N|Step 6: Verify Persistence and Storefront Output
P145|IMG=N|Reload the theme editor and confirm settings remain unchanged. Open or refresh the storefront and verify text, colors, order, display mode, and desktop/mobile behavior.
P146|IMG=N|Saving Behavior
P147|IMG=N|The reference image does not show a dedicated Save Changes or Publish button. Use the theme platform’s existing save and publish workflow. If the platform uses autosave, display a saving status and communicate errors when saving fails.

P195|IMG=N|Final Implementation Goal
P196|IMG=N|The Promotional Announcements component must provide a complete, customizable announcement management experience within the e-commerce theme. P197|IMG=N|Scope restriction: These requirements apply exclusively to the Promotional Announcements component. Do not add unrelated global store settings or features outside this component’s scope. Maintain a modular implementation so other theme components can be developed consistently in the future.

P207|IMG=N|1. Purpose and Scope
P208|IMG=N|Build the “Featured Categories & Products Section” as a configurable component inside the e-commerce theme editor. It allows a merchant to create multiple sections, configure category tabs or custom pages, choose products, control comparison and “View More” actions, and customize the product layout. The component must work on desktop, tablet, and mobile.
P209|IMG=N|Scope is limited to this component. Reuse the theme platform’s existing product catalog, settings persistence, preview, and publish workflows. Do not add unrelated global store settings.

P211|IMG=N|2.1 Back Button
P212|IMG=N|Returns to the previous theme-editor screen. It should not silently discard unsaved changes; if there are unsaved edits, warn the user or rely on the editor’s established draft/autosave behavior.

P214|IMG=N|Opens or focuses the storefront preview using the current draft settings. The preview should clearly indicate whether it is showing unpublished changes, if the platform supports draft previews.
P215|IMG=N|2.3 Save Changes
P216|IMG=N|Validates and saves the component configuration using the existing theme settings system. Show a clear success or error state. Do not report success until saving has completed. If the platform separates saving from publishing, explain that saving alone may not publish changes to the live storefront.
