## 1. AI-Generated Code Audit

Google AI Studio code ko completely audit karo. Check + **fix**:

| Area | Look for |
|------|----------|
| Quality | Coding mistakes, broken logic, duplicate code/components |
| Cleanup | Unnecessary code, unused imports/packages, dead code |
| Runtime | Console errors, API errors |
| Security | Auth holes, exposed secrets, weak validation |
| Performance | Heavy re-renders, N+1 queries, huge bundles |
| Data | Wrong queries, wrong permissions, **tenant isolation** gaps |
| App | Incorrect routing, cache/update / stale data problems |

- Jo feature **correctly** kaam karta hai → unnecessarily rewrite **mat** karo.  
- Sirf mistakes + gaps fix / connect.
