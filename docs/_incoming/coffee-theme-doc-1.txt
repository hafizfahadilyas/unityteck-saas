





Homepage Interface Elements

The attached document contains 20 Homepage Theme Elements designed to manage and customize the storefront interface.
1. Complete List of Elements
1. Promotional Announcements
Displays promotional announcements, special offers, discounts, and advertising messages across the storefront.
2. Main Menu
Manages the main navigation menu, including categories, subcategories, featured products, and navigation links.
3. Hero Banners
Displays the main promotional banners and large advertising campaigns on the storefront homepage.
4. Featured Section Banners
Displays promotional banners for featured sections, including images, promotional text, product details, and action buttons.
5. Featured Products Section
Displays featured products with category tabs, product cards, highlighted products, and shopping buttons.
6. Image Banner Section
Displays promotional images with customizable titles, descriptions, buttons, colors, and visual effects.
7. Footer Section
Manages the store footer, including navigation links, contact information, newsletter subscriptions, social media links, and copyright information.
8. Feature Icons Section
Displays store benefits and services using icons, titles, and descriptions, such as fast shipping, warranty, returns, and customer support.
9. Product Carousel Section
Displays products in a horizontally navigable carousel with product images, prices, options, and purchase buttons.
10. Category Showcase Section
Showcases product categories with promotional banners and product listings in a customizable layout.
11. Benefits Section
Displays store benefits, services, and customer advantages through customizable cards containing icons, titles, descriptions, and action buttons.
12. Events & Masterclasses Section
Displays events, workshops, training sessions, and masterclasses, including event images, descriptions, and registration links.
13. Features Section
Displays product features, technical specifications, and key selling points using individual feature cards.
14. Model Comparison
Allows customers to compare different products and models based on their images, prices, and technical specifications.
15. Customer Reviews
Displays customer ratings, product reviews, feedback, and uploaded customer photos, with review approval controls.
16. Frequently Asked Questions (FAQ)
Displays frequently asked questions and answers using expandable and collapsible question items.
17. Commercial Hero Section
Displays commercial products with their main information, pricing, purchase buttons, and key technical features.
18. Product Slider Section
Displays selected products in a horizontal slider with navigation controls, product cards, and shopping buttons.
19. Product Catalog Section
Manages the complete product catalog, including product categories, filtering, sorting, pricing, stock information, and product browsing.
20. Product Collection Section
Displays a selected product collection with a promotional card, product slider, and benefit boxes.

Theme Component: Promotional Announcements


Promotional Announcements
1. Action Button & Link
Controls the promotional banner's call-to-action button.
Show Action Button: Enable or disable the button.
Button Text: Customize the button label, such as "Shop Now".
Link (URL): Set the destination URL that opens when the customer clicks the button.
2. Display Settings
Controls how the promotional banner appears on the storefront.
Display Mode – Full Width: Makes the banner stretch across the full available screen width.
Display Mode – Boxed: Displays the banner inside a centered container with limited width.
3. Appearance
Controls the banner's visual appearance.
Text Color: Change the color of the banner text using a color picker or HEX code.
Background Color: Customize the banner background color.
Banner Height: Control the vertical height of the banner using predefined or custom values.
4. Responsive Preview
Allows the administrator to preview the promotional banner on different screen sizes.
Desktop: Preview the banner on desktop screens.
Tablet: Preview the banner on tablet screens.
Mobile: Preview the banner on mobile devices.
5. Apply & Publish Changes Live
Saves and publishes the configured banner settings to the live storefront.
Applies all updated content and design settings.
Updates the storefront with the latest configuration.
Makes the changes visible to customers after publishing.
Important: All sections should remain accessible and editable, without hiding any settings or controls.







Main Menu – Settings & Controls Guide
Element Name: Main MenuElement ID:main-menu
Objective: Build a fully functional Main Menu management panel that allows store owners to manage navigation categories, subcategories, featured products, product comparisons, and responsive menu layouts across desktop, tablet, and mobile devices.
1. Section Information
Controls the main menu's basic information.
Enable Section: Enable or disable the main menu.
Section Title: Set the menu title.
Section Description: Add an optional description.
2. Category Tabs – Main Navigation
Manage the main navigation categories and their hierarchy.
Add Category: Create a new menu category.
Category Image: Upload or select a category image.
Category Name: Enter the category name.
Category Type: Choose between Main Category, Subcategory, or Custom Page.
Drag & Drop: Reorder menu categories.
Edit: Modify category details.
Delete: Remove a category.
Parent Category: Assign a subcategory to its main category.
3. Products Management
Control the products displayed within the menu.
Product Source: Select products manually or from existing categories.
Sort By: Arrange products by Manual Order, Price, Newest, or Best Selling.
Number of Products to Display: Set the number of products shown.
Product Selection: Add or remove products from the menu.
Product Order: Arrange products manually.
4. Product Comparison Settings
Control product comparison functionality.
Enable Compare Button: Enable or disable product comparison.
Maximum Products to Compare: Set the maximum number of comparable products.
Comparison Button Text: Customize the comparison button label.
Comparison Page: Select the destination comparison page.
Select Products Available for Comparison: Choose eligible products.
Remove Product: Remove a product from the comparison list.
5. View More Button Settings
Manage the button that directs customers to additional products or categories.
Show View More Button: Enable or disable the button.
Button Text: Customize the button label.
Link To: Select the destination, such as Same Category or Custom Page.
6. Display Settings by Device
Customize how the main menu appears on different devices.
Desktop: Configure the desktop menu layout.
Tablet: Configure the tablet menu layout.
Mobile: Configure the mobile menu layout.
Layout Options:
Horizontal Scroll: Display categories or products in a horizontally scrollable row.
Grid (2 Columns): Display products in a two-column grid.
Number of Columns: Set the number of visible columns.
Show Category Tabs: Show or hide category navigation tabs.
Show Compare Button: Show or hide the comparison button.
Card Style: Choose Rounded or Square product cards.
Card Spacing: Set Small, Medium, or Large spacing between cards.
7. Device Preview
Preview the main menu on different screen sizes.
Desktop Preview: Preview the desktop navigation.
Tablet Preview: Preview the tablet navigation.
Mobile Preview: Preview the mobile navigation.
Live Preview: Display changes immediately while editing.
8. Apply & Publish Changes Live
Save all menu settings.
Apply category and product changes.
Update the navigation layout.
Publish changes to the live storefront.
Display success or error notifications.
Technical Requirements
All settings must be functional and connected to the actual storefront.
Support nested categories and subcategories.
Allow drag-and-drop category ordering.
Save category and product configurations in the database.
Support independent responsive layouts.
Update the preview immediately when settings change.
Preserve existing configurations when editing categories.
Ensure all navigation links work correctly.
Do not hide or remove any existing controls.
Maintain responsive behavior across all supported devices.
Important: The element must function as the store's main navigation menu, not as a standalone product showcase. All categories, subcategories, navigation links, and product interactions must work correctly on the live storefront.

FOOTER SECTION
Developer Specification
Complete settings, column and link management, contact information, newsletter, social media, bottom bar, save workflow, and responsive requirements
1. Purpose and Scope
The Footer Section is a configurable store-wide component displayed at the bottom of storefront pages. It organizes navigation links, category links, store/contact information, newsletter signup, social media links, country/region selection, copyright text, and legal or utility links. The component must be manageable from the theme editor and responsive across desktop, tablet, and mobile.
This specification combines the three supplied reference screens: (1) footer appearance and column management, (2) editing a footer column and its links, and (3) contact information, newsletter, social media, and bottom bar settings. Keep this as one Footer Section with logically grouped subsections.
2. Global Page Actions
2.1 Back to Dashboard / Back to Columns
Back to Dashboard returns to the main admin dashboard. Back to Columns returns from the Edit Column view to the main footer-column list. If edits are unsaved, follow the platform’s established draft behavior or warn before discarding them.
2.2 Preview Store
Opens the storefront preview using the current draft configuration where supported. Previewing must not publish changes.
2.3 Save Changes
Validates and saves the full footer configuration. Show success only after the save operation completes. If saving fails, preserve the current edits where possible and display a useful error. If the platform has a separate publish step, do not claim that the live storefront has changed until publishing is complete.
3. Enable Footer
The Enable Footer switch controls whether the entire footer is rendered on the storefront. When off, hide the footer but retain all its settings in the editor. Turning it on restores the saved configuration.
4. Layout Settings
4.1 Color Controls
Background Color: sets the overall footer background.
Text Color: sets the default footer text color.
Link Color: sets the default color of footer links.
Link Hover Color: sets the color used when a visitor hovers over a link on pointer-based devices; use a suitable focus/active treatment for keyboard and touch accessibility.
Provide a color picker and valid HEX input where shown. Update the preview immediately and validate color values. Ensure the selected colors provide sufficient contrast.
4.2 Columns (Desktop)
Selects 1, 2, 3, or 4 columns for the desktop footer layout. The layout must distribute enabled columns consistently and wrap or adapt gracefully if there are more columns than fit.
4.3 Section Width
Full Width: footer content spans the available viewport width, while internal padding keeps content away from screen edges.
Boxed: footer content is constrained to a centered maximum-width container.
4.4 Font Size
Sets the default footer font size, for example 14 px. Use a responsive scale where needed and preserve readable sizes on small screens.
4.5 Column Spacing
Sets the gap between footer columns, for example 40 px. Reduce spacing responsively when the available width becomes limited.
4.6 Content Alignment
Controls alignment, including Right (RTL) for Arabic layouts. Support left-to-right and right-to-left direction without reversing the meaning or destination of links.
5. Footer Columns
5.1 Column List
Lists the configured columns with a drag handle, order number, title, item count/type label, enabled switch, and actions.

Column title and item count: identify the column and summarize its contents.
Enable/Disable switch: hides or shows that column without deleting its configuration.
Edit: opens the column editor.
Copy: duplicates the column and its settings/links with a new unique ID; avoid duplicate IDs or unintended duplicate external actions.
Delete: removes the selected column after confirmation if appropriate. Do not delete its underlying categories, pages, products, or media records.
5.2 Add Column
Adds a new footer column. The merchant chooses one of the available column types:
Categories Column: shows links to product categories/collections.
Custom Links: lets the merchant create a list of manually configured destinations.
Information Column: displays configured store information or informational links, depending on the theme’s implementation.
Contact Column: displays selected contact details.
Newsletter Column: displays the email subscription form.
After selection, create a new column with a unique ID, a suitable default title, enabled state, and type-specific empty/default settings. Do not publish placeholder content automatically.
6. Edit Column
6.1 Column Title
Sets the heading shown above the column in the storefront. The reference shows a 50-character limit and a live character counter.
6.2 Column Type
Defines the column’s content type, such as Product Categories. Changing type may change which settings are available. Preserve compatible data where possible and warn before discarding incompatible settings.
6.3 Icon (Optional)
Allows the merchant to choose an icon for the column heading, change it, or remove it. If no icon is selected, display the title without an icon. Use consistent sizing and accessible labels.
6.4 Enable Column
Controls whether the column is eligible to appear in the footer. Disabled columns remain editable and retain their settings.
6.5 Column Order
Sets the column position numerically. Changes must synchronize with drag-and-drop ordering and be validated so positions remain consistent.
6.6 Show in Desktop / Show in Mobile
